# trollrunner-games — retired

This repo is no longer used. The Troll Runner Arcade now lives in the main
site repo, [mayurski-art.github.io](https://github.com/mayurski-art/mayurski-art.github.io).

**Play the arcade:** https://trollrunner.net/games.html

## What moved

Every game that was live here was ported into the main repo — the hub page
(`games.html`), each game's page, and its assets under `assets/games/`:

Troll Kombat · Troll Dash: Meme Metro · Trollrreria · Trollrreria 3D ·
Troll High · Troll Casino · Papa Troll's Pizzeria · Troll Ops · NULLFACE ·
Backrooms · The Rusty Troll

## What did not move

- **Bridge Patrol** and **Troll TD** were retired and deliberately not carried over.
- **Grin Halls** was superseded by **Backrooms**, its newer rebuild, which
  ships in the main repo instead.
- Unlinked dev/scratch pages (`wallet-lab.html`, `troll-pizzeria-3d-preview.html`,
  `trollrreria-3d-localtest.html`).

The `games.trollrunner.net` subdomain was also retired; use `trollrunner.net/games.html`.
