🏫 Troll High — Zone Editor

Dev tool only, not linked from the arcade. Paints against the real Wang tilesets so the preview matches the game exactly.

Zone
Tool
Terrain brush

Click a grid intersection to toggle one vertex. Drag a rectangle to bulk-fill with the current brush.

Object palette

Click to place the selected object (snaps to its footprint). Right-click an object to remove it.

Doors

Drag a rectangle on the canvas to add a door, then set its target below.

Spawn point

Click a tile to set where the player appears.
